# CanCan 2D

CanCan 2D, tarayicida oynanan ucretsiz 2D strateji oyunudur. Yerel iki oyuncu ve online oda linki ile oynanabilir.

## Dosyalar

- `cancan.html`: Ana oyun dosyasi.
- `online-server/`: Online oda sistemi icin WebSocket relay server.
- `ONLINE_DEPLOY_FREE.md`: Ucretsiz online server deploy rehberi.
- `LAUNCH_PLAN.md`: SEO, Itch.io, Reddit ve ilk oyuncu toplama plani.
